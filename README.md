# 🍯 Beekeeping Pletený Újezd – Static Website

A responsive single-page website presenting a beekeeping project from Central Bohemia.  
The website focuses on nature, sustainability, and traditional craftsmanship, using a warm honey-inspired design and modern web features.

👉 [View the live site](https://lenkalaznovska.github.io/Bee_web/)

## 📄 Project Overview

This project showcases a local beekeeping initiative, highlighting its philosophy, natural products (honey, propolis tincture), and connection to nature.  
The website is static, lightweight, and fully responsive – suitable for both mobile and desktop.

It includes:

- Introduction to the beekeeping philosophy
- Product descriptions with health benefits
- Animated flip-card photo gallery
- Call-to-action section for product interest
- Responsive design and smooth scrolling
- Social media preview metadata (Open Graph, Twitter Cards)

---

## 🛠️ Technologies Used

### 💻 Frontend

- **HTML5** – semantic and structured markup  
- **CSS3** – responsive styling, variables, shadows, animations  
- **JavaScript** – intersection observer, scroll-to-top button, animations

### 📷 Assets & Layout

- Flip-card based image gallery (honey, bee, tincture)
- Custom scroll animations (fade-in, breathing effect)
- Golden accents and natural palette with CSS variables

---

## 🎨 UI Features

- 🐝 **Animated Section Reveal** – uses `IntersectionObserver` to animate content on scroll  
- 📸 **Flip Card Gallery** – interactive visual display of products  
- ⬆️ **Scroll to Top Button** – animated button appears when scrolling  
- 🎯 **Call to Action** – animated section encouraging visitors to contact/order  
- 📱 **Mobile Optimized** – content adapts to all screen sizes using media queries

---

## 📱 Responsiveness & Accessibility

The layout is responsive across:
